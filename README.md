# Operations Data Quality & Process Monitoring Dashboard

## Project Overview

This project demonstrates an Excel-based operational monitoring and data quality analysis workflow using a simulated dataset of 200 operational records.

The dashboard was designed to monitor workflow status, pending workload, information completeness, data quality, process volume, and processing time.

## Objectives

- Monitor operational workflow status
- Identify pending work and priorities
- Track missing information
- Evaluate data quality
- Analyze process volume
- Monitor average processing time
- Present operational insights through an Excel dashboard

## Dataset

The project uses a simulated dataset containing 200 operational records.

Key fields include:

- Record ID
- Customer
- Process Type
- Received Date
- Status
- Missing Information
- Processing Days
- Accuracy Check
- Priority
- Assigned Team

## Key Metrics

- Total Records: 200
- Completed Records: 109
- Pending Records: 38
- Records with Missing Information: 55
- Average Processing Time: 4.67 days
- Data Quality Pass: 156 records
- Data Quality Review: 44 records

## Dashboard

The Excel dashboard includes:

- Process Volume by Type
- Pending Work by Priority
- Data Quality Status
- Information Completeness
- Operational KPI cards
- Key Operational Insights

1. Prepared the operational dataset
2. Reviewed and validated the data

6. Calculated operational KPIs
7. Built an Excel dashboard
8. Summarized key operational insights

## Important Note

This project uses a simulated dataset created for portfolio and learning purposes. It does not contain real customer, provider, healthcare, or confidential business information.
